# Home Hero Hub

Build a high-fidelity "Uber for Home Maintenance" web application. The platform should connect homeowners with verified skilled contractors (plumbers, electricians, handymen, and gardeners) for immediate or scheduled service.

Key features and functionality 

Dual-User Interface: A seamless toggle or separate onboarding flow for 'Customers' and 'Service Providers'.

Service Catalog: A clean, icon-based grid to select service categories (e.g., Plumbing, Electrical, Landscaping).

Booking Engine: >     * Instant Request: Find the nearest available pro (Uber-style).

Scheduled: Pick a date/time slot.

Live Map Integration: A dashboard showing the user's location and available pros nearby using a map component.

Job Management: >     * For Customers: Real-time status updates (Heading to job, Arrived, Job in Progress, Completed).

For Pros: A "Job Feed" to accept or decline nearby requests and a "My Schedule" view.

Payment & Reviews: An integrated checkout flow for job completion and a 5-star rating/review system for each contractor.

Design Aesthetic:

Style: Professional, trustworthy, and modern. Use a "Clean Tech" aesthetic (similar to Thumbtack or Uber).

Color Palette: Trust-inducing blues or greens paired with high-contrast white and slate grey.

Components: Use rounded cards, clear call-to-action buttons, and progress steppers for active jobs.

Mention Your Tech Stack: If you have a preference, add "Built with React, Tailwind CSS, and Supabase for the backend/auth."

• Focus on the "Mobile-First" Aspect: Since users will likely use this on their phones while looking at a leaky pipe, ask Loveable to "Prioritize a mobile-responsive layout that feels like a native app."

• Iterate on the Map: Once the initial UI is built, you can follow up with: "Now, make the map functional using a mock set of coordinates for nearby plumbers."
